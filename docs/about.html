About Project

Project Overview

This project builds a credit card approval risk intelligence platform using credit datasets. Machine Learning classifiers analyze demographic features (income, housing, education) and evaluate applicant repayment patterns to output binary decisions: Approved or Rejected.

Business Problem

Traditional credit card approvals depend on slow manual audits or simplistic credit scoring models. False Negatives (approving high-risk clients who default) directly result in major credit losses for financial institutions. Automating this scoring process using a highly tuned binary classifier helps reduce write-offs while keeping customer acquisition cost (CAC) low.

Objectives

  • Perform visual profiling and exploratory analysis of demographic data.
  • Engineer risk indicators (debt ratios, age groupings, unemployment tags).
  • Balance training samples using random oversampling to handle severe credit default class imbalances.
  • Evaluate and compare Logistic Regression, Random Forest, and XGBoost classifiers.
  • Package and deploy using Docker, Gunicorn, and SQLite logs storage.
