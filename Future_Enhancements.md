# Future Enhancements

The following roadmap items will be prioritized for future system enhancements:

1. **Retrieval-Augmented Generation (RAG)**: Integrate LLM agents to provide natural language explanations for card approvals or rejections to applicants.
2. **Deep Learning Classifiers**: Integrate PyTorch-based Multilayer Perceptrons (MLPs) alongside XGBoost.
3. **Model Drift Monitoring**: Set up Evidently AI dashboards to track feature drift online.
4. **CI/CD Cloud Deployment**: Extend GitHub Actions workflows to auto-build Docker containers and push to IBM Container Registry.
