## 📅 Project Planning & Gantt Schedule

The CreditGuard AI development schedule followed standard Agile Scrum iterations:

| Sprint | Goal Target | Deliverable Task | Status |
| :---: | :--- | :--- | :---: |
| **Sprint 1** | Audit & Lint | Bandit security audit, Pytest baseline, env setup | Completed |
| **Sprint 2** | Design System | Custom glassmorphism CSS templates, wizards UI | Completed |
| **Sprint 3** | Core Services | Preprocessors integration, LIME surrogate math | Completed |
| **Sprint 4** | Database | SQLite users schema, query ledger persistency | Completed |
| **Sprint 5** | Cloud Deploy | Vercel Serverless configurations, /tmp redirects | Completed |

### Work Breakdown Structure (WBS)
```
1.0 Data Ingestion & Model Serialization (src/main.py)
 └── 1.1 Deduplication & Outlier Capping (1.5 IQR)
 └── 1.2 SMOTE Oversampling & Scaling
2.0 Backend Service (app/app.py)
 └── 2.1 Flask App Factory & WTForms Validation
 └── 2.2 scrypt Encryption & Session Filters
3.0 UI Design (app/static/css/index.css)
 └── 3.1 Glassmorphic Dashboard Charts (Chart.js)
 └── 3.2 SVG Probability Gauge & CountUp Wizard
```
