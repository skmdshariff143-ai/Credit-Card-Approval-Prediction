# User Guide

This guide explains how to navigate and use the **CreditGuard AI** web application interface.

---

## 1. Landing Dashboard (Home)

When you open `http://localhost:5000`, you will land on the Home page:
- **Project Goal:** Review the core classification objectives.
- **Model Summary:** Observe the F1-scores of candidate algorithms trained by the pipeline.
- **Theme Toggle:** Switch between Dark and Light mode using the theme button in the top right.

---

## 2. Running a Risk Prediction

To score a credit applicant:
1. Click **Predict Risk** in the navigation bar.
2. Fill out the application profile form:
   - **Demographics:** Gender, Age, Marital Status, and Family counts.
   - **Assets & Income:** Gross Annual Income, Car/Property ownership indicators.
   - **Employment:** Occupation class and Years Employed. If the client is retired or unemployed, toggle the switch: this will automatically lock "Years Employed" to `0`.
3. Click **Run Risk Prediction**.
4. Observe the results screen:
   - **Status Badge:** Displays *Approved* (Low risk) or *Rejected* (High default risk).
   - **Confidence Score:** The probability generated by the underlying model.
   - **Risk Attributions:** Visualizes which client properties supported approval or added risk.

---

## 3. Reviewing Prediction logs

To audit previous calculations:
1. Click **History Log** in the navbar.
2. View the tabular list of registered transactions, ordered by timestamp.
3. To export the database, click the **Export Logs** dropdown in the top right:
   - Click **Download CSV** to download a spreadsheet.
   - Click **Download JSON** to download a raw database dump.
