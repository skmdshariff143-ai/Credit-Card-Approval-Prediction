Platform Overview

Active Model: {{ best_model_name }}

CreditGuard AI is an advanced machine learning platform built to predict credit card application defaults. Due to severe class imbalance in standard application databases (where non-default accounts exceed default files by 99:1), the training dataset is processed using Synthetic Minority Over-sampling Technique (SMOTE). Classifiers are fitted using stratified cross-validation before deploying the optimal parameters.

Platform Data Pipeline Flow

1. Imbalance Fix

SMOTE balances target variables before estimator training to prevent default predictions skew.

2. Feature scaling

Calculates income-to-family ratios, encodes categorical assets, and normalizes numeric values.

3. Model Inference

Evaluates fitted XGBoost/Random Forest parameters to generate the raw default probability.

4. Rule Overlay

Validates DTI safety bounds and credit history defaults, overriding machine learning scores on risk triggers.
