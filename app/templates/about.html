Project Overview & Business Problem

In retail banking, credit card issuance represents a balance between maximizing credit access and minimizing default rates. Traditional manually-reviewed risk assessment is slow and prone to subjective inconsistencies.

CreditGuard AI implements a supervised machine learning binary classifier that evaluates applicant information at scale. By using historical repayment records, the system flags default default risk ($\ge 60$ days delinquent status) as Class 1 (Rejected), and stable repayment profiles as Class 0 (Approved).

Machine Learning Workflow

1. Ingestion
Validate bounds and shape schemas.
2. Processing
Cap outliers, impute nulls, engineer features.
3. Modeling
Train baseline, cross-validate, GridSearch tune.
4. Serving
REST API endpoints and Flask scoring.

Model Performance & Auditing

The models were trained on 5-fold Stratified Cross-Validation on the balanced training partition and evaluated on an unseen test partition. Because credit card defaults represent severe loss, we prioritized Recall (the ratio of high-risk defaults detected) over simple Accuracy.

Algorithm F1-Score ROC-AUC Recall Balanced Accuracy
Logistic Regression (Deployed) 0.2387 0.7409 66.67% 0.6744
XGBoost Classifier 0.2047 0.7001 17.33% 0.5656
Decision Tree Classifier 0.1975 0.5683 21.33% 0.5683
Random Forest Classifier 0.1930 0.7174 14.67% 0.5582
Note: Tree-based ensemble models suffer from majority class overfitting, predicting very few default cases. Logistic Regression with balanced weighting generalizes best to default risk.

Dataset Summary

  • Source: Kaggle Credit Card Approval
  • Total Demographics: 5,000 application rows
  • Total History: 163,037 monthly records
  • Approved Class (0): 92.50%
  • Default Class (1): 7.50%

Future Improvements

  • Credit History Windowing: Incorporate temporal trend features.
  • Anonymization: Apply differential privacy to applicant features.
  • Model Retraining Loop: Automatic pipeline updates on new monthly credit logs.
