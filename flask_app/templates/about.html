About CreditGuard AI

An end-to-end production-grade machine learning system for credit risk prediction.

Project Overview

Credit card approval prediction is a classic financial classification problem. Banks and financial institutions receive thousands of credit card applications daily. Evaluating applicant risk manually is slow, prone to human error, and expensive. This system automates the process using a multi-stage machine learning pipeline.

By joining demographic data with historical payment history (defining creditworthiness based on defaults/delinquencies over 60 days past due), we train robust predictive models to automate decision boundaries. The system dynamically ranks candidates and outputs a decision along with the model's confidence probability.

Model Performance & Architecture

Four algorithms are evaluated and compared in the training pipeline: Logistic Regression (baseline & interpretability), Decision Tree, Random Forest, and XGBoost Classifier. Hyperparameters are tuned using GridSearchCV optimizing for F1-Score to protect against the high imbalance of default cases.

Algorithm Strengths Use Case
Logistic Regression High interpretability, fast inference, clear odds ratios. Regulatory auditing & simple baselines.
Decision Tree Non-linear boundaries, easy rules visualizer. Rule-based policy generation.
Random Forest Reduces variance, robust to outliers, calculates feature importances. General production bagging model.
XGBoost Gradient boosting, optimized regularization, state-of-the-art accuracy. Current deployed model (Best F1-Score).

Cloud Integration

The model is ready to be deployed to the IBM Cloud using IBM Watson Machine Learning (WML). Once deployed, the application can route online requests directly to the cloud endpoint for highly scalable distributed scoring.
