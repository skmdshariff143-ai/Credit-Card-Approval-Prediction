# Release Notes - v1.0.0

We are proud to announce the **v1.0.0 Release** of CreditGuard AI Credit Card Approval prediction system.

---

## Key Features
1. **Audited ML Pipeline**: Complete pipeline featuring outlier capping, median imputation, oversampling, and feature selectors.
2. **REST API Scoring**: JSON predict `/api/predict` endpoint, schema validator checks, and local JSON history logs manager.
3. **Containerized Execution**: Optimized multi-stage `Dockerfile` and Gunicorn configuration ready for Vercel serverless deployments.
4. **Diagnostic Monitoring**: Active `/health` diagnostics endpoint returning current loaded model metadata.
5. **System Diagrams**: High-resolution Architecture, ER schemas, and Flowcharts.
6. **Pass Rate**: 100% pytest suite execution coverage.
